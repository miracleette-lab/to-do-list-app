# Daymark

A beginner-friendly to-do list that helps you choose what to work on first. It runs in your browser and does not need a server, account, or installed packages.

## Open the app

1. Open the project folder.
2. Double-click `index.html` (or right-click it and choose your browser).
3. Select **New task**, fill in the task details, and save.

Your tasks stay in the same browser on this device. Clearing that browser's site data removes them, so this first version is best for personal use on one device.

## How the priority score works

Tasks receive a score from 0 to 100 and are sorted from highest to lowest. Importance contributes 35%, urgency 30%, the deadline 25%, and estimated effort 10%. Closer deadlines add points; quick tasks receive a small boost. Use the score as a guide and choose what feels right.

## Files

- `index.html` contains the app's structure.
- `styles.css` controls the layout, colors, and responsive design.
- `app.js` manages tasks, browser storage, and priority scoring.
